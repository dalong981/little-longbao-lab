# 小龙包科学实验室 (Little Longbao Lab) 🧪✨

> **“在 AI 和短视频时代，用厨房常备物，每周陪 7 岁女儿完成一个真实可触碰的物理科学实验。”**
>
> 培养物理直觉、因果推理与自主构建习惯（Agency），沉淀公众号「小龙包爸爸」核心内容。

---

## 🌟 为什么要做这个项目？

1. **从“屏幕消费者”到“现实构建者”**：
   当下算法与短视频让孩子习惯了虚拟世界的即时反馈，缺乏对物理世界摩擦力与因果律的掌控感。
2. **超越学校的纸上谈兵**：
   学校科学课多以理论讲授和死记概念为主，缺乏亲自动手的探索过程。真实的科学思维源于“动手做、观察、调试”。
3. **建立马斯克式的物理第一性原理**：
   物理学是理解世界的底层契约。7 岁时在厨房玩出的表面张力、流体粘度、气压变化，将转化为终身受益的具身直觉。

---

## 🧭 协同机制与工作流

本实验室采用 **“Linear 追踪推进 + GitHub 沉淀资产 + Agent 全程协同”** 的现代工程化闭环：

```
[ Linear Issue ]  -->  [ 亲子实验指南 (guide.md) ]
       │                         │
       ▼                         ▼
[ 亲子实操与探索 ] -->  [ 现场观察日志 (journal.md) ]
                                 │
                                 ▼
                     [ 公众号推文草稿 (wechat-draft.md) ]
```

* **Linear 项目**：[小龙包科学实验室](https://linear.app/long-chen/project/小龙包科学实验室-63f5807aa7df)
* **每周节奏**：
  * **周四**：生成本期《亲子实验指导卡》（`guide.md`），核对厨房物资；
  * **周六**：30-45 分钟亲子实操（女儿担任“首席科学家”，爸爸担任“实验助手”）；
  * **周六晚**：速记对话与翻车细节，归档至 `journal.md`；
  * **周日**：提炼第一性原理与亲子感悟，生成公众号推文 `wechat-draft.md`；
  * **闭环**：Git 提交并标记 Linear Issue 为 Done。
